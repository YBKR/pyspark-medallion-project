# PySpark Medallion Architecture Project

## 🔧 Tech Stack
- PySpark, Databricks Community Edition
- Medallion Architecture (Bronze → Silver → Gold)
- Python, SQL

## 📦 Datasets
- BigMart Sales Data (CSV) — Retail sales analytics
- F1 Drivers Data (JSON) — Nested JSON processing

## 🏗️ Architecture
Bronze → Raw ingestion
Silver → Cleaned & transformed
Gold  → Analytics-ready aggregations

## 🚀 How to Run
1. Upload data to Databricks FileStore
2. Run notebooks in order (01 → 05)

## 📊 Key Insights
- Top selling product categories
- Outlet-wise sales performance
- F1 driver nationality distribution
